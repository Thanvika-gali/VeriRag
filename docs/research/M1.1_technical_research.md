## 1. Executive Summary

As Large Language Models (LLMs) are deployed across high-stakes domains (healthcare, law, scientific research, financial intelligence), mitigating and detecting **hallucinations**—statistically plausible yet ungrounded or factually incorrect claims—is critical. 

Traditional heuristic evaluation metrics (such as BLEU, ROUGE, and METEOR) rely strictly on surface-level n-gram overlap with reference texts. They fail to capture factual nuances, semantic paraphrasing, logical consistency, and unsupported extrapolations.

**VeriRAG** is engineered as an automated, evidence-grounded validation framework. This document presents the technical foundations of response validation, claim-level verification, RAG retrieval mechanics, evaluation framework paradigms (RAGAS, TruLens), and benchmark dataset dynamics.

## 2. Evaluation Dimensions & Taxonomy

VeriRAG decomposes response validation into four orthogonal dimensions:

```
                                  AI Response Evaluation
                                            │
        ┌───────────────────┬───────────────┴───────────────┬───────────────────┐
        ▼                   ▼                               ▼                   ▼
  1. Relevance        2. Factuality & Faithfulness    3. Hallucination    4. Completeness
 (Intent & Directness) (Evidence Support & Truth)   (Fabricated Claims) (Aspect & Scope Coverage)
```

### 2.1 Topical Relevance
- **Definition:** The degree to which the AI-generated response directly addresses the user's prompt without topic drift or evasive verbosity.
- **Metric Formulation:** Evaluates semantic alignment between Query Intent $Q$ and Answer Content $A$:
$$\text{Relevance}(Q, A) = \text{Sim}(E(Q), E(A_{\text{claims}}))$$

### 2.2 Factuality vs. Faithfulness
- **Factuality:** Alignment of claims with world knowledge and established empirical ground truth (e.g., historical dates, scientific facts).
- **Faithfulness (Groundedness):** Strict entailment of the generated claims with respect to the provided/retrieved source evidence $C$. A response is faithful if and only if every assertion can be inferred directly from $C$:
$$\text{Faithfulness}(A, C) = \frac{|\{c \in \text{Claims}(A) \mid C \models c\}|}{|\text{Claims}(A)|}$$

### 2.3 Hallucination Detection & Claim-Level Decomposition
Hallucinations are categorized into:
1. **Extrinsic Hallucinations:** Claims that cannot be verified or contradicted from reference context (unsupported assertions).
2. **Intrinsic Hallucinations:** Claims that directly contradict statements in the reference context.

**Claim-Level Verification Strategy:**
1. **Atomic Claim Extraction:** Parse response $A$ into discrete, independently verifiable proposition tuples $\{c_1, c_2, \dots, c_n\}$.
2. **Evidence Alignment:** Retrieve relevant context chunks $E(c_i)$ for each claim.
3. **NLI Entailment Classification:** Determine whether $E(c_i)$ entails (`SUPPORTED`), contradicts (`CONTRADICTED`), or is neutral (`UNGROUNDED`) towards $c_i$.

### 2.4 Completeness & Coverage
- **Definition:** Assesses whether all sub-questions, explicit constraints, and requisite technical aspects posed in $Q$ were resolved in $A$.
- **Methodology:** Extract question requirements $\{r_1, \dots, r_m\}$ and compute coverage ratio against verified response points.

## 3. Comparative Analysis of Evaluation Frameworks

| Feature / Dimension | RAGAS (RAG Assessment) | TruLens (TruEra) | VeriRAG Approach |
| :--- | :--- | :--- | :--- |
| **Core Architecture** | Component-wise RAG metrics | The RAG Triad feedback loops | Multi-agent modular evaluation pipeline |
| **Groundedness Metric** | `faithfulness` via claim splitting | `groundedness` via NLI/LLM reasoning | Claim-level multi-evidence entailment |
| **Context Quality** | `context_precision`, `context_recall` | `context_relevance` | Dense similarity distance + metadata scoring |
| **Local / Offline Mode** | Requires configured embeddings/LLM | Supports local Hugging Face models | 100% local M1 pipeline (`all-MiniLM-L6-v2` + ChromaDB) |
| **Source Doc Ingestion** | Raw string inputs | Data app instrumentations | Native multi-format parser (TXT, PDF via `pypdf`) |
| **Benchmark Integration**| Generic evaluation datasets | Custom app logging | Hugging Face TruthfulQA + SQuAD native ingestion |

### 3.1 Key Lessons from RAGAS and TruLens
1. **Decouple Retrieval Quality from Generation Quality:** A poor evaluation score may stem either from retrieval failure (relevant evidence never reached the judge) or generation failure (model ignored retrieved evidence).
2. **Claim Atomicity:** Aggregated sentence-level scoring introduces noise; breaking text into atomic propositions yields higher inter-annotator agreement.
3. **Deterministic Pre-Filtering:** Applying dense semantic similarity checks before agentic judging minimizes LLM inference overhead and prevents judge hallucination.

## 4. RAG Architecture & Dense Retrieval Pipeline

### 4.1 Embedding Space & Model Selection
- **Chosen Embedding Model:** `sentence-transformers/all-MiniLM-L6-v2`
- **Dimensionality:** 384 dimensions
- **Parameters:** 22.7M parameters
- **Rationale:** Optimized for semantic search and sentence similarity tasks; executes in sub-10ms latency on standard CPUs without GPU acceleration requirements.
- **Distance Metric:** Cosine Similarity / Cosine Distance:
$$\text{Cosine Sim}(u, v) = \frac{u \cdot v}{\|u\|_2 \|v\|_2}, \quad \text{Distance} = 1 - \text{Cosine Sim}(u, v)$$

### 4.2 Configurable Chunking Strategy
- **Splitter:** Recursive character text splitting prioritizing paragraph breaks (`\n\n`), sentence boundaries (`. `, `? `, `! `), and word tokens (` `).
- **Chunk Size ($500$ chars) & Overlap ($50$ chars):** Selected to maintain semantic cohesion for factual statements while avoiding splitting critical context across chunk boundaries.
- **Metadata Envelope:** Each chunk retains parent document ID, chunk index, dataset origin, and source reference.

## 5. Benchmark Datasets Analysis

### 5.1 TruthfulQA (`truthfulqa/truthful_qa`)
- **Structure:** 817 questions spanning 38 categories (misconceptions, health, legal, conspiracies, science).
- **Value in VeriRAG:** Explicitly designed to elicit common human false beliefs and model mimicry of falsehoods. Serves as our primary benchmark for truthfulness and anti-hallucination verification.

### 5.2 SQuAD (`rajpurkar/squad`)
- **Structure:** 100,000+ question-answer pairs derived from Wikipedia articles with rigorous ground truth context passages.
- **Value in VeriRAG:** Provides comprehensive factual, topic-diverse reference contexts with verified ground truth answers for evaluating retrieval precision and factual alignment.

## 6. Limitations & Milestone 2 Roadmap

### Limitations in Milestone 1:
- Retrieval is dense-only (vector similarity); hybrid sparse/dense (BM25 + Dense) reranking will further improve keyword-heavy queries in future milestones.
- LLM Judge agents are decoupled as placeholders for M2; M1 focuses on evidence grounding and retrieval fidelity.
